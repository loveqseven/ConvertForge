Can ConvertForge convert every file type?

The library includes many conversion pages, but browser technology cannot safely perform every professional conversion. Unsupported heavy conversions are explicitly identified instead of generating invalid output.

Do you store uploaded files?

Browser-supported conversions do not require upload. If server-side processing is added for a tool, the page should clearly explain how that processing works.
