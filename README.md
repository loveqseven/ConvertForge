# ConvertForge — All-in-One Online Converters

Static, SEO-friendly converter website inspired by the general workflow of modern online converter services. It is an original implementation and branding.

## Included
- Universal converter homepage
- 80+ SEO tool pages generated from a converter catalog
- Image conversions that run in the browser (PNG/JPG/WEBP/SVG where supported)
- Text/data conversions for TXT, JSON, CSV, HTML, XML, Markdown
- Image-to-PDF conversion using PDF-LIB CDN
- Client-side privacy messaging for browser conversions
- Search, categories, related tools, FAQ sections, breadcrumbs, canonical URLs
- robots.txt, sitemap.xml, ads.txt, About, Contact, Privacy, Terms
- Responsive design and ad-ready placements

## Important
A static browser app cannot honestly perform every professional DOCX/PDF/video/audio/CAD conversion. Those pages are wired into a clear backend/API hook so they can be connected later to FFmpeg, LibreOffice, CloudConvert, ConvertAPI, or another conversion service without redesigning the site.
